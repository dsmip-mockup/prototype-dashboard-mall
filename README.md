# Prototype Dashboard Management — PT SMIP

Mockup **konsep tampilan** untuk rapat manajemen PT Summarecon Mall Investama Perkasa.
Dibuka langsung di browser, termasuk dari HP dan tablet.

> ## Seluruh angka di dalam mockup ini adalah DATA CONTOH
>
> **Tidak ada satu pun angka riil perusahaan di sini.** Angkanya dibangkitkan generator
> deterministik dan dibuat wajar serta saling konsisten semata-mata supaya tampilannya bisa
> dinilai — bukan untuk dibaca sebagai laporan. Jangan dipakai sebagai dasar keputusan, dan
> jangan dikutip sebagai angka Summarecon.

Repositori ini memuat **satu berkas** hasil build (`index.html`). Kode sumbernya tidak ada di
sini; ia dikembangkan di repositori internal.

Versi yang sedang terbit tertulis di kaki halaman mockup-nya sendiri ("Versi ⟨tanggal⟩") —
gunakan itu waktu menyampaikan komentar, supaya jelas versi mana yang dilihat.
